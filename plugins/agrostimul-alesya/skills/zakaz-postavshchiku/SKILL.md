# Заказ поставщику в МоёмСкладе

Пишем Алесе (Алтунина Алеся Витальевна, помощник директора) по-русски, на «ты». Работаем в браузере (Claude в Chrome или встроенный браузер приложения), Алеся уже вошла в МойСклад под своим входом. Перед первым шагом загрузить навык браузера (chrome-browser или built-in-browser). Работать в своей новой вкладке, в конце её закрыть.

## 1. Сверка с данными (коннектор Agrostimul System)
- Для каждой позиции заявки найти карточку инструментом `product` (поиск по заводскому обозначению — оно в конце названия — и по названию; все слова запроса должны найтись). Архивные — повторить с `archived: true`.
- Разложить на три списка: есть активная карточка / есть в архиве / нет — заводить.
- Показать этот разбор одним сообщением; вопросы — только если что-то неоднозначно.

## 2. Новые карточки — только с пустой формы
- URL: `https://online.moysklad.ru/app/#good/edit?new&type=Good`. Никогда не «Копировать» — копия тащит галочку выгрузки на Kaspi, ссылку, NTIN и сразу сохраняется.
- Наименование: заводское обозначение в КОНЦЕ названия через пробел (например, «Привязь цепная для собак L-3000 мм 00.00.1479А»). Поле «Артикул» не трогать — там артикул Kaspi.
- Группа, поставщик, единица измерения, НДС 16%.
- Цены в карточке — в ТЕНГЕ: закупочная = цена поставщика × коэффициент поставщика (курс × доставка; коэффициент спросить у Вадима или взять из карточки поставщика в Летописи; для ЧВМЗ в ноябре 2026 было 4,055 ₸ за 1 ₽ прайса). **Цена продажи — только согласованная с Вадимом**, кратная 100 ₸; не согласована — оставить пустой и сказать.
- После сохранения URL меняется на `edit?id=…` — это подтверждение. Проверять поля через JS: `[...document.querySelectorAll('input')].map(e=>e.value)`.

## 3. Архивные товары
- По прямой ссылке архивный может не открыться. Искать в списке товаров: Фильтр → «Показывать: Все», поиск по названию.
- В карточке: «…» → «Извлечь из архива», обновить закупочную; продажу — только согласованную с Вадимом; при необходимости перенести из «Вывести из ассортимента» в нужную группу (с согласия Вадима). Сохранить.
- Цены Kaspi (мин. и «Цена Каспий») в карточке не трогать, но если они ниже новой себестоимости / 0,6 — сказать.

## 4. Заказ поставщику
- URL: `https://online.moysklad.ru/app/#purchaseorder/edit?new`.
- Контрагент — поставщик. Статус «Формируется». Галочку «Проведено» СНЯТЬ.
- **Российский поставщик:** валюта — руб (RUB), курс по умолчанию 6 (реальный курс ставит Вадим при оплате); во всех позициях НДС «без НДС».
- **Казахстанский поставщик:** валюта — тенге, НДС по позициям ставим.
- Цены в заказе, по порядку источников: прайс → спецификация → счёт поставщика; ничего нет — последняя закупочная цена (из карточки, инструмент `product`); нет и её — 0. Цены до копеек.
- Добавление позиций: поле «Добавить позицию» (фокус через JS по placeholder, начинается с «Добавить позицию»), вводить УНИКАЛЬНЫЙ кусок названия, подождать 3 с, Enter → количество, Enter. После каждой партии проверять список: поиск может подставить не тот товар. Лишнюю строку — галочка строки → «Удалить».
- Цены и НДС по строкам: клик в ячейку первой строки, ввод, Enter — курсор переходит в ту же колонку следующей строки. НДС: ctrl+a, «без», пауза, Enter. Не нажимать Escape — он вызывает диалог закрытия (выбрать «Отмена»).
- Комментарий внизу — по шаблону:

```
Заказ подготовлен с помощью Claude, создан Алтуниной А. В.
Основание: <прайс-лист / спецификация №… / счёт №… от дд.мм.гггг>.
Состав: <N позиций>, <M единиц>.
Сумма: <сумма> RUB.
Доставка:
НДС:
Итого:
```

  Доставку, НДС и Итого оставить пустыми. Особые условия — строкой «Примечание: …» в конце.
- Сохранить, проверить: «Заказ сохранен», общая стоимость = сумме заявки (расхождение в копейки — назвать), сумма НДС 0,00 у российского поставщика.

## 5. Итог
- Номер заказа, сумма, число позиций, что заведено новым, что достано из архива, что требует внимания Вадима (цены продажи, курс).
- Заказ поставщику НИКОМУ не отправлять — отправка и оплата только по решению Вадима.
- Новый поставщик или важная договорённость — передать в Летопись (навык «Летопись»: заметка во «Входящие»).

## Подводные камни браузера
- Скриншоты иногда виснут — проверять через JS или открыть новую вкладку.
- Клик «Сохранить» по координатам иногда не срабатывает — искать кнопку через find и кликать по ref.
- Всплывающая реклама «Онлайн-заказ» в правом нижнем углу перекрывает ячейки — закрыть крестиком.
