# Что заказать

Пишем Алесе (Алтунина Алеся Витальевна, помощник директора) по-русски, на «ты», как толковый помощник: факты, честная оценка. Только чтение: заказы поставщикам этот навык НЕ создаёт — после решения заказ заводится навыком «Заказ поставщику». Ничего не придумываем: чего нет — «нет данных», а не ноль. Партнёра всегда писать «Агний». Рядом с каждым товаром — артикул Kaspi.

Главное правило (решение директора): **не сидеть без товара**. Без прогнозов «закончится через N дней»: свободный остаток + уже заказано меньше неснижаемого → заказать до неснижаемого, округлив вверх до кратности. Неснижаемый остаток задаёт Вадим Владимирович в карточке МоегоСклада.

Если Алеся назвала поставщика («что заказать у Феникса») — только по нему.

## Источники — коннектор Agrostimul System (роль Алеси)

- `stock` с `below_min: true` (можно добавить `supplier`, `folder`, `query`) — товары ниже неснижаемого. Колонки: `supplier`, `status` («Держим» / «Вывести» / «Под заказ»), `available` (свободно = остаток − резерв), `min` (неснижаемый), `multiple` (кратность), `ordered` (уже в открытых заказах поставщикам — от «Отправлен» до «Частично принят»; черновик «Формируется» сюда не входит), `shortfall` (сколько не хватает до неснижаемого, с учётом заказов покупателей сверх склада), `draft` (сколько заказать — до неснижаемого, с округлением вверх до кратности). Время — `data_as_of`.
- `product_sales` с `period: "90"`, `channel: "all"` (и `supplier`, если назван) — продажи за 90 дней. Брать **`qty_parts`** (свои штуки + проданные в комплектах), а не `qty`: иначе детали, которые уходят в наборах, выглядят непродаваемыми. Продажи обновляются ночью.
- `supplier_orders` (`supplier`, если назван) — открытые заказы поставщикам: номера, статусы, плановая дата, есть ли черновик «Формируется», куда можно дописать.

Запросы — параллельно. Группировку по поставщикам делаем сами по колонке `supplier`.

## Разбор

Берём строки `stock below_min`, у которых `draft` больше 0. «Вывести» и «Распродажа» не заказываем никогда.

1. 🔴 **Кончилось и продаётся** — свободно 0 или меньше, продажи за 90 дней есть, в заказах ничего нет.
2. 🟡 **Ниже неснижаемого и продаётся** — остальные строки с продажами.
3. **Без продаж за 90 дней** — не список, а одна строка: «ещё N позиций без продаж ниже неснижаемого — может, Вадиму Владимировичу снизить неснижаемый? Список по просьбе».

Попутно у товара одной строкой (не правилом):
- продали за 90 дней больше, чем весь неснижаемый, — «неснижаемый, похоже, мал»;
- товар уже в открытом заказе, но и с ним не хватает — «в заказе № N мало»;
- у поставщика есть черновик «Формируется» — его количество в `ordered` не входит: «есть черновик № N, может, там уже есть».

Сроки поставки у поставщиков разные (Феникс отгружает с задержками). Плановую дату брать из заказа (`supplier_orders`), не придумывать.

## Как подавать

Заголовок: «## Что заказать, на <ЧЧ:ММ>» (время данных).

По поставщикам — сначала те, у кого больше 🔴. Внутри — 🔴, потом 🟡, по убыванию продаж. Строка товара: название по-человечески, артикул рядом, **заказать N** (это `draft`) жирным, в скобках «есть M, в заказе K, неснижаемый X, продали Y за 90 дней». Пример:

> **Дед Алтай** — 🔴 2, 🟡 12
> - 🔴 Соль нитритная 200 г (арт. 132709703_152643128) — **заказать 29** (есть 0, неснижаемый 29, продали 155 за 90 дней — неснижаемый, похоже, мал)
> - 🟡 Набор трав «Джин» (арт. 108849366_579402370) — **заказать 20** (кратность 5; есть 22, в заказе 0, неснижаемый 38, продали 45)

Агний — отдельным поставщиком, как остальные.

В конце:
- **Главное** — 2–3 предложения: у кого заказывать в первую очередь.
- Последней строкой: «Завести заказ? Скажи, у кого — сделаю по навыку «Заказ поставщику»».

Голосом — только поставщики и самое срочное (🔴), без артикулов, числа словами.

Если `stock` не знает `below_min` (старая версия коннектора) — сказать: «в коннекторе ещё нет списка „ниже неснижаемого“ — у коннектора нажми „Обновить список инструментов“ или попроси Степаныча»; руками не собирать.
