# Запуск робота Kaspi по просьбе

Робот сам обходит кабинет Kaspi и Kaspi Маркетинг в 06:15, 10:00, 13:00, 16:00 и 19:00. По просьбе Алеси — внеочередной обход. Работает из любого чата и голосом: нужен только коннектор Google Drive (аккаунт agrostimul.sklad). Обход занимает около 2 минут.

## Как запустить

1. Узнать текущее время.
2. Если сейчас с 01:00 до 06:00 — сказать, что ночью робот не ходит, просьба не выполнится; файл не трогать.
3. Google Drive `update_file`: fileId `1x0sAMmpEJ4-qgQuSjnf6wfIUx-zcDF3Z` (файл `robot-zapusk`), `description` = «запуск ГГГГ-ММ-ДД ЧЧ:ММ — Алеся». Описание должно отличаться от прежнего — время это гарантирует. Содержимое файла не трогать, файл не удалять и не переименовывать.
4. Засечь время просьбы — `modifiedTime` из ответа `update_file` (по Гринвичу, +5 часов — наше время).
5. Сказать одной фразой: «Запустил в ЧЧ:ММ, свежие данные будут примерно через 2 минуты».

Нет доступа на правку файла (`update_file` отказал) — сказать: «У меня нет права запускать робота — попроси Вадима открыть мне файл robot-zapusk на правку»; плановые обходы при этом идут как обычно.

## Как показать результат

- Если просили «запусти и посмотри» — через ~2 минуты (или на следующий вопрос) сделать сводку по навыку «Каспий полностью».
- Свежесть — по `modifiedTime` файла `robot-kaspi-otzyvy.json` (fileId `1xX74mUdErM-uNj4qV8lOGMjf7KsDKUwu`, `get_file_metadata`) и по `updated_at` внутри: должно быть позже времени просьбы. Ещё старое — «робот ещё идёт, данные на ЧЧ:ММ», старое за новое не выдавать.
- Одной строкой перед сводкой — «от просьбы до свежих данных N мин M с».
- Через 5 минут выжимка не обновилась — честно: обход не прошёл или ещё не начался, сказать Вадиму.

## Правила

- Только по просьбе, сам по себе не запускать.
- Чаще раза в 10–15 минут не запускать: частые входы Kaspi может заметить. Прошлый обход был только что — показать то, что уже есть.
- По-русски, на «ты», коротко.
