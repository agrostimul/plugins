# Отзывы и рейтинг Kaspi — из выжимки робота

Пишем Алесе (Алтунина Алеся Витальевна, помощник директора ТОО «Агростимул.KZ») по-русски, на «ты», человеческим языком. Работаем как толковый помощник-аналитик: факты из выжимки, честная оценка, готовые тексты. Ничего не придумываем. Решения по магазину принимает директор — Вадим.

Отзывы и рейтинг собирает робот новой системы Агростимул — на сервере, в 06:15, 10:00, 13:00, 16:00, 19:00 (плюс внеочередной обход по просьбе), без компьютера. После каждого обхода он кладёт выжимку в файл `robot-kaspi-otzyvy.json` на Диске agrostimul.os; Алесе (agrostimul.sklad) файл открыт.

## Главные правила

- Только читаем. Файл выжимки не менять: его перезаписывает робот. Жалобы в Kaspi и ответы покупателям сами НЕ отправляем — тексты готовим, отправляет человек.
- **Разобранные отзывы не повторяем.** Список — в памяти этого аккаунта, файл `/areas/kaspi-otzyvy.md`. Если его ещё нет — взять стартовый список из раздела «Разобрано до 19.11.2026» в конце навыка.
- Браузер не нужен. Выжимка не читается — сказать одной фразой и предложить внеочередной обход (навык «Запуск робота»).

## Шаг 0. Что уже разобрано

Прочитать `/areas/kaspi-otzyvy.md` (memory_read) и взять номера заказов уже разобранных отзывов. Файла нет — разобранные = стартовый список в конце навыка.

## Шаг 1. Выжимка

Google Drive: `read_file_content`, fileId `1xX74mUdErM-uNj4qV8lOGMjf7KsDKUwu` (не находится — `search_files`: `title = 'robot-kaspi-otzyvy.json'`). Файл большой (70+ КБ): разбирать скриптом `python3 -I`. Коннектор Диска экранирует текст: сначала `\\` → `\`, затем регуляркой `\\([^"\\/bfnrtu])` → `\1`, потом `json.loads`.

Поля:
- `updated_at`, `run.status` (`ok` / `warn` / `error`), `run.note` — когда и как прошёл обход. Если `updated_at` раньше последнего планового обхода больше чем на 30 минут или статус не `ok` — первой строкой честно: «данные на ДД.ММ ЧЧ:ММ, обход был с ошибкой/давно».
- `rating` — рейтинг магазина: `rating`, `count`, `from`/`to` (90 дней), `stars` («5»…«1»), `threshold` (порог Kaspi 4,0), `updated_at`. Нет ключа — «нет данных».
- `months.current`, `months.previous` — какие месяцы сравнивать.
- `negative` — отрицательные за 90 дней: `date, order, rating, author, product, category, text, plus, minus`.
- `positive_by_month` — по месяцам за год: `count, with_text, with_photo`.
- `positive_by_category` — по группам, текущий и прошлый месяц.
- `top_products` — товары по числу отзывов, текущий и прошлый месяц.
- `praise` — за что хвалят, по ключевым словам.
- `remarks` — кандидаты в «замечания внутри хороших» (сырой отбор по словам; ложные вроде «но думаю хороший» выбросить).

## Шаг 2. Рейтинг

Одной-двумя строками: оценка и число оценок, запас до порога 4,0, сколько единиц и двоек. Например: «4,9 по 922 оценкам за 90 дней, порог 4,0 — запас большой; единиц 4, двоек 3».

## Шаг 3. Новые отрицательные

Из `negative` отбросить те, чей номер заказа уже разобран. Разбирать только новые. При нужде заказ можно найти в коннекторе Agrostimul System, инструмент `kaspi_orders` с параметром `number`.

## Шаг 4. Две кучки

**Жаловаться есть смысл** — отзыв не про товар (курьер, доставка, сроки Kaspi), оскорбления, реклама/контакты, отзыв на другой товар. Дать готовый текст жалобы и что приложить.

**Жаловаться бесполезно** — претензии по делу (качество, комплектация, «не помогло»). Дать готовый ответ покупателю: извиниться или объяснить, предложить решение (замена, дослать деталь, инструкция, совет). Плюс строка «Для нас:» — что проверить у себя. Обещания от имени фирмы (замена, возврат денег) — пометить «согласовать с Вадимом перед отправкой».

Честно оговаривать: точные правила снятия отзывов Kaspi не сверены, оценка по практике.

## Шаг 5. Положительные

Период: текущий месяц против прошлого; 1–5 числа — прошлый месяц целиком против позапрошлого.
1. **Динамика**: сколько за месяц против прошлого, доля с текстом и с фото. Текущий месяц неполный — сравнивать по темпу.
2. **По группам** — месяц против прошлого. «Аксессуары для кухонной техники» у нас — это запчасти к дистилляторам, так и называть.
3. **Топ товаров**, родственные вместе (наборы колбасника, оболочки). Названия короче («Дед Алтай» убрать, «набор колбасника» → «НК»).
4. **За что хвалят** — из `praise`.
5. **Замечания внутри хороших** — только настоящие и неразобранные; каждое одной строкой + что поправить. Повтор прежнего — сказать, что проблема не решена.

## Шаг 6. Закономерности

Новые вместе с разобранными раньше: повтор жалобы (нет инструкции, недокомплект, соль в приправе, брак партии) — сказать прямо и что поправить.

## Шаг 7. Записать разобранные

После ответа дописать в `/areas/kaspi-otzyvy.md` (нет файла — создать и сначала перенести туда стартовый список):
`- [stated] asked to remember: разобраны <ДД.ММ.ГГГГ> — заказы №<номер> (<имя>, <товар>), ...`
`- [stated] asked to remember: замечания из положительных разобраны <ДД.ММ.ГГГГ> — заказы №<номер> (<товар>, суть), ...`
Новых не было — ничего не писать.

Если разбор нашёл что-то важное для компании (повторяющийся брак партии, проблема поставщика) — предложить Алесе записать в Летопись (навык «Летопись»: заметка во «Входящие»).

## Как подавать

1. Данные не свежие или обход не `ok` — одна строка.
2. **Рейтинг** — одна-две строки.
3. «Новых плохих отзывов: N» (и сколько уже разобрано раньше).
4. «Жаловаться есть смысл» — отзыв + текст жалобы отдельным блоком для копирования.
5. «Жаловаться бесполезно, лучше ответить» — свежие сверху; отзыв одной строкой (имя, товар, дата, суть) + ответ отдельным блоком + «Для нас:».
6. **Хорошие отзывы**: динамика, таблица по группам, кого хвалят больше всего, за что.
7. **Замечания внутри хороших** — нумерованный список «что поправить».
8. «Главный вывод» — 2–3 предложения; нет — пропустить.

Правила текстов: ответ — на языке отзыва (казахский пометить: проверить человеку, хорошо знающему язык); коротко, вежливо, без спора с покупателем. Рядом с товаром — артикул Kaspi, если известен (найти можно инструментом `product` коннектора Agrostimul System по названию).

## Режимы

- «Отзывы» → всё выше.
- «Рейтинг» → только Шаг 2.
- «Плохие отзывы» → шаги 0–4, 6–7.
- «Хорошие отзывы» → шаг 5.
- Голосом — без текстов ответов и таблиц: рейтинг, сколько новых плохих и про что, сколько хороших за месяц, главное замечание. Артикулы не называть.
