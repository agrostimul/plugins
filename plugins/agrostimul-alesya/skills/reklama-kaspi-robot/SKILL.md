# Реклама и бонусы Kaspi — из выжимки робота

Пишем Алесе (Алтунина Алеся Витальевна, помощник директора ТОО «Агростимул.KZ») по-русски, на «ты», человеческим языком. Цифры из выжимки, честная оценка, конкретные предложения. Решения по бюджетам принимает директор — Вадим. Ничего не придумываем: чего нет — «нет данных», а не ноль.

Данные собирает робот новой системы Агростимул — на сервере, в 06:15, 10:00, 13:00, 16:00, 19:00 (плюс внеочередной обход по просьбе), только чтение. Выжимка — раздел `reklama` файла `robot-kaspi-otzyvy.json` на Диске agrostimul.os (имя файла историческое).

## Главные правила

- Только читаем. В Маркетинге ничего не меняем — ни бюджеты, ни кампании, ни акции. Файл выжимки не трогаем. В конце ответа: «Сам я в кабинете ничего не менял».
- Период — текущий месяц с 1-го по сегодня. В первые 2–3 дня месяца выводы ранние — сказать одной фразой.
- Выжимка не читается — одной фразой и предложить внеочередной обход (навык «Запуск робота»).

Файл большой — разбирать скриптом `python3 -I`; экранирование коннектора: `\\` → `\`, затем `\\([^"\\/bfnrtu])` → `\1`, потом `json.loads`. Нужен ключ `reklama`:

## Шаг 2. Выручка Kaspi за месяц (для доли продвижения)

Коннектор Agrostimul System (ToolSearch `select:mcp__Agrostimul_System__channel_sales`): `channel_sales` с `month` = текущий месяц «ГГГГ-ММ» → `channels`, строка «Каспий магазин», `revenue` — выручка «Прибыльности» (продажи минус возвраты). Так и называть: «выручка Kaspi за месяц». Коннектор недоступен — долю не считать, сказать «выручка не посчитана».

## Шаг 3. Оценка кампаний

По доле расходов (`crr`):
- **Окупается хорошо** — до 10%.
- **Дорого** — больше 10%. Для крупных по расходу — конкретное предложение (снизить бюджет до …, пересобрать товары); мелочь до 1–2 тысяч — одной строкой.
- **Впустую** — расход есть, заказов нет, или доля больше 100%. Много кликов и ноль заказов = проблема карточки (цена, фото, описание, отзывы).
- **Не показывается** — `state = Enabled`, а `views_7d = 0`.

Честно оговаривать: Kaspi считает заказы щедро (один заказ может попасть и в рекламу, и в бонусы); у дорогого оборудования итог часто держится на 2–5 крупных заказах; бонусы на товар — скидка с каждой продажи. Наценку по товарам кампании не знаем — не придумывать.

## Как подавать

1. **Итог месяца**: всего на продвижение = реклама + бонусы на товар + бонусы за отзыв, и доля от выручки Kaspi за месяц.
2. **Реклама:** расход и доля; группы «Окупается хорошо» / «Дорого» / «Впустую» / «Не показывается» (пустые не выводить). По кампании — строка: название, заказы на сумму, расход, доля.
3. **Бонусы на товар:** по акциям — заказы, сумма, выплачено.
4. **Бонусы за отзыв:** сообщений, отзывов, выплачено, цена одного отзыва.
5. **Что предложить** — 3–5 пунктов, самое дорогое первым. Добавить товар в уже работающую кампанию и бонусы за отзыв Алеся решает сама (навык «Поступление», шаги 4–5); новая кампания, её бюджет, остановка кампании — только Вадим Владимирович: такие пункты — списком «для Вадима Владимировича». В конце: «Сам я в кабинете ничего не менял».

Суммы — в тысячах и миллионах с одним знаком («16,8 тысячи», «1,4 млн»). Голосом — только итог, одна-две кампании из «Дорого» и «Впустую» и что предложить.
